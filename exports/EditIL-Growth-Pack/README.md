# חבילת התוכן של EditIL

החבילה מיועדת ל־TikTok, ל־YouTube Shorts ול־Instagram Reels ביחס 9:16.

## הסרטונים

- `01-community-promo.mp4` — סרטון היכרות עם הקהילה.
- `02-resources-promo.mp4` — סרטון שמציג את ערך המשאבים והמדריכים.
- `03-editing-challenge.mp4` — סרטון הזמנה לאתגר עריכה.

הסרטונים ללא מוזיקה כדי שאפשר יהיה לבחור סאונד טרנדי בזמן הפרסום. מומלץ להוסיף מוזיקה בעוצמה של 15%–25% ואפקט קצר בכל מעבר.

## פרסום מומלץ

- לפרסם 4–5 סרטונים בשבוע.
- להשאיר את `editil.com` על המסך ובקישור הפרופיל.
- לענות לכל תגובה אמיתית בשעה הראשונה.
- לא להעלות את שלושת הסרטונים באותו יום.
- לבדוק אחרי שבעה ימים איזה פתיח השיג את זמן הצפייה הגבוה ביותר וליצור לו וריאציות.

הכיתובים המוכנים נמצאים ב־`captions.md`, והתוכנית המלאה נמצאת ב־`30-day-plan.md`.
